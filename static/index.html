Mapa de la cadena

Mapa 3D estilizado e isométrico. Los pines se colocan con posiciones normalizadas (x/y) guardadas para cada ubicación; no es un mapa geográfico. Las ubicaciones marcadas como de demostración se etiquetan como datos ficticios.

Datos ficticios de demostración Cargando ubicaciones…

    Aún no hay ubicaciones cargadas. El panel administrativo puede añadirlas o ejecutar el comando seed-demo-locations.

    Las ubicaciones etiquetadas como datos ficticios de demostración usan nombres y direcciones inventados; no corresponden a sucursales reales. Las demás son ubicaciones reales de la cadena.
